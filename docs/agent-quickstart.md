# 代理从注册到出第一单：完整流程详解

> 配合官方四步流程（注册账号 → 联系客服 → 知识库学习 → 开始分销），把每一步拆成可执行的动作清单。目标是第一周内跑通全流程。

## 第一步：注册账号（约 10 分钟）

**做什么**
1. 访问 [ka172.cn/agent](https://www.ka172.cn/agent)，点击「注册代理」
2. 填写手机号获取验证码，设置密码
3. 填写邀请码（获取方式见[主页指南](../README.md)）
4. 提交实名信息（姓名与身份证需一致）

**易错点**
- 邀请码提交后通常不可修改，填之前核对一遍
- 实名信息必须与本人身份证完全一致，影响后续佣金结算

## 第二步：联系客服（当天）

**做什么**
- 注册完成后主动联系客服，完成账号审核
- 确认自己的代理级别与对应佣金政策
- 让客服拉你进新手指引群（有素材与答疑）

**要问清的三件事**
1. 我的佣金结算模式是秒返还是次月？
2. 提现门槛和到账时间是多少？
3. 新手有没有专属的扶持卡品？

## 第三步：知识库学习（1~2 天）

**学什么（按优先级）**
1. 卡品知识：通用流量 vs 定向流量、合约期、归属地限制——自己都不懂，讲不清给用户
2. 平台规则：佣金计算、结算周期、售后边界
3. 推广方法：平台提供的素材库与话术，先照抄再改造

**检验标准**：能用三句话向一个完全不懂的朋友讲清楚「这张卡是什么、多少钱、怎么办理」。

## 第四步：开始分销（第 3~7 天出首单）

**动作清单**
1. 在卡品中心挑 1~2 个主推套餐——新手建议选通用流量高的全国卡，售后最少
2. 生成专属推广链接，自己先走一遍下单流程测试
3. 发布到自己的渠道（朋友圈/社群/短视频简介）
4. 用户下单激活后，佣金自动入账
5. 收到首笔佣金后，设置提现并确认到账——跑通整个闭环

## 第一周节奏建议

| 时间 | 目标 |
| --- | --- |
| 第 1 天 | 注册 + 审核完成 |
| 第 2~3 天 | 知识库学习 + 选定主推卡品 |
| 第 4~5 天 | 首条推广内容发布 |
| 第 6~7 天 | 首单激活、佣金闭环验证 |

## 常见卡点

- **审核没通过**：检查实名信息与身份证是否一致，联系客服看具体原因
- **不知道选什么卡**：先用[对比工作表](https://github.com/haoka172/172-card-guide/blob/main/docs/compare-worksheet.md)自己当用户比一遍
- **推广没反应**：素材照抄平台的转化率最高，别急着自创
