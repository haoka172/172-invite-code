# 代理注册前核对清单

> 注册 172 号卡分销系统之前，逐项过一遍，避免注册后才发现不符合预期。

## 注册前

- [ ] 确认邀请码来源是官方页面（[ka172.cn/agent](https://www.ka172.cn/agent)），不是第三方转述
- [ ] 准备好本人实名手机号（用于验证码与实名）
- [ ] 了解佣金结算模式：秒返与次月结算的区别
- [ ] 明确自己的推广方式（自媒体 / 网推 / 地推），影响后续选品

## 注册时

- [ ] 邀请码与手机号填写无误（提交后通常不可改）
- [ ] 实名信息与身份证一致
- [ ] 记录注册时间与账号信息

## 注册后第一周

- [ ] 登录后台，完成新手教程
- [ ] 在卡品中心挑 1~2 个主推套餐，生成推广链接
- [ ] 测试推广链接的落地页是否正常打开
- [ ] 核对佣金结算规则与提现方式（支付宝 / 微信 / 银行卡）
- [ ] 收藏官方客服入口，遇到问题先问客服

## 判断渠道是否靠谱

- 正规卡可在运营商官方 App 查询到卡与套餐
- 佣金规则后台明示、提现记录可查
- 客服响应及时，不回避合约期、注销等细节问题
